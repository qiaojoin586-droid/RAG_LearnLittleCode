## 处理原则与校准

事实、结构、数据落点和遗漏项纳入修订；需要分期的内容明确唯一主责，不把全部企业化工作塞进 M1。以下三点按代码/证据校准，而非机械复述建议：

- F2：超限时先没有生产者写队列，流等待；进入取消/结束清理时才会对 None 调 done 并异常，不写成两个现象必定同时立即发生。
- G4：固定文本向量探测仅能发现不一致，不能证明任意跨服务向量空间等价；可信修订证据不足就阻止切换或重建。
- G13：目标原生端点选 /api/embed；官方参考缺少旧页面不能证明全部已部署版本的 /api/embeddings 都返回 404，本地锁定 SDK 仍保留旧方法。维度能力按服务商/模型判断，不把 OpenAI 的限制推广到 Ollama。
