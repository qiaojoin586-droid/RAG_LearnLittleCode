# M1 显式 Responses 与跨服务备用

本地开发环境。对应 M1-17、M1-18。模型配置页的 OpenAI 兼容聊天角色默认使用 Chat Completions，可显式选择 Responses。角色探测通过后方可发布。请求使用 `store: false`，图片和结构化输出映射到 Responses 对应字段，函数调用与结果通过 `call_id` 关联。运行时归一化文本和用量，只在完成事件后交付函数调用。专用思考进度角色仍受原有供应商能力门控。

跨服务备用沿用单次重试窗口。管理员需要分别开启主备端点策略的跨服务选项，并用源角色的能力要求测试备用模型。主备须处于同一环境和网络类型，使用同一适配器与协议，并通过上下文预算兼容检查。第二次调用使用备用端点自己的密钥，发布快照、主备撤销检查和原任务上下文继续生效。

M1-13 沿用管理员核验现有索引原始建库记录的流程。当前缺少可信记录的旧索引保持待核验。自动来源证明与新索引重建纳入 M3 索引迁移工作。

回归覆盖草稿、能力探测、发布、LangChain 调用入口、流终止、工具 ID、用量、跨服务凭据隔离和缺少端点许可时的拒绝。通过后端 636 项、前端 127 项、隔离 MySQL 88 项和配置契约 89 项。前端构建与 lint 通过。模型端点使用离线 HTTP 夹具，实际云端和 Ollama 实例仍待联调。本批未重启本地业务服务，迁移演练只在隔离库执行。
