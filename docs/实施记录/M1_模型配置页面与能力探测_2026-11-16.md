# M1 模型配置页面与能力探测实施记录

日期：2026-11-16。继续上一批控制面实施，部署范围为本地开发、尚未上线。交付可编辑的模型配置页面和有真实 HTTP 实现的受控能力探测；不代表完整 M1 验收通过。

## 用户可用路径

头像菜单 → **模型配置**（`/model-config`）。17 个角色在一个页面，按基本/高级分组；窄屏使用角色下拉选择。首次需按[上一批初始化步骤](./M1_模型配置控制面首批实施_2026-11-16.md)初始化主密钥及现有用户的配置管理授权，普通用户不会因用户名或前端按钮获得权限。

1. 管理员登记云端 HTTPS 或可信私网端点策略。策略只保存允许的地址和路径，不联网。Ollama 本机常用 `http://127.0.0.1:11434`、路径 `/`，显式允许 `127.0.0.1/32`；使用 localhost 时还应允许 `::1/128`。其他主机/容器的地址按后端实际网络填写。
2. 新建或选择草稿，在各角色编辑 Base URL、模型、认证、Key、超时、提示词和受限 JSON 参数。模型与提示词作为同一 PATCH 原子保存；替换/清空 Key 和新建策略要求密码重新认证。
3. 保存后再编辑独立/跟随/动态模型绑定、启停和失败策略。绑定独立保存，避免未知的新修订 ID 被旧绑定覆盖。动态跟随仅 synthesize 可选，提示词仍属于本角色。
4. 点击“测试已保存配置”，测试对应草稿版本。界面展示通过/未通过/未验证与具体能力，测试成功不标记为已发布。

接口冲突保留未保存文本；同体重试沿用 Idempotency-Key。换角色、换草稿或重新读取会提示放弃未保存内容，刷新/关闭页面有 beforeunload 保护。其他 SPA 导航尚无统一路由拦截，离开页面前仍须保存。Key 输入默认为隐藏，成功保存后清除；密码提交后立即清除，proof 只在本次调用内使用，均不新增浏览器持久化。

只读配置角色禁用编辑/测试。所有服务端操作仍检查 JWT、黑名单、当前账号及 grant；前端显示和按钮禁用不替代授权。

## 后端能力与约束

新增 `/api/v1/model-config/drafts/{id}/test` 和 `/validations/{id}`，分别复用 config.test/config.read 权限映射。DraftTestInput 为 role_key、expected_draft_version、可选 budget=standard/local_cold；测试写入要求 If-Match 和 Idempotency-Key。默认总截止 30 秒，可信私网可选 90 秒；单请求仍受模型配置中的连接/读取超时约束。每任务最多 3 次出站尝试、每次最多 96 输出 Token，接口每用户每分钟最多 3 次受理检查。

| 角色/协议 | 实际测试行为 | 不能推断的结论 |
| --- | --- | --- |
| 普通文本角色 | 解析 SSE 或 Ollama NDJSON，要求正文与终止标记 | 本轮可用不代表长期在线 |
| chat/chat_thinking/vision | 流式 + 随机 nonce 的 echo_test 工具往返，共最多 3 次请求 | 不运行任何业务工具，不探测视频理解 |
| classifier/planner/ppt_outline/auto_tag/review_question/reflection/memory_extraction | 固定 JSON Schema 请求并严格验证返回对象 | 仅验证基础结构化能力，业务角色输出契约仍待集成 |
| vision | 固定测试图片的输入与流式响应 | 图片通过不证明视频通过或视觉语义质量达标 |
| chat_thinking | Ollama think / DashScope enable_thinking 参数测试 | 不读取或要求隐藏推理；其他兼容端点的控制语义保留 unverified |
| embedding | 固定双文本，校验数量、索引位置类型/次序、维度和有限数值 | 维度相同不能证明向量空间兼容，semantic_identity 仍 unverified |
| DashScope 原生向量 | 原生路径、显式 Bearer Key、query 语义和 dimension；无 SDK 全局 Key | 不切换或重建原有向量索引 |
| Responses | 当前保留 unverified/未实现原因 | 不自动改用 Chat Completions 或宣布支持 |

所有测试使用代码固定消息，忽略业务提示词正文，不发送笔记、个人记忆或历史会话。上游响应正文、请求头及任意异常文本不写测试结果或审计；返回固定错误原因。测试结果明确 `business_prompt_contract_verified=false`，不能作为完整业务模板验证或发布许可。

参考接口事实使用[OpenAI Chat Completions 官方文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)、[Ollama 官方 API](https://github.com/ollama/ollama/blob/main/docs/api.md)；连接实现依据 [httpcore network backend 接口](https://www.encode.io/httpcore/network-backends/)。实际适配版本为 guarded-http-v1，结果保留精确 target_spec/JCS hash、角色/策略/凭据版本与 24 小时证据期限。

## 出站与任务正确性

- GuardedTransport 使用 httpcore network_backend：DNS 解析后全部地址需通过策略；只拨号一个批准的 IP，不二次解析主机名；检查实际 peer，TLS 使用原主机名校验证书。公有模式拒绝私网/保留/映射地址及已知元数据地址，私网模式仅允许显式 CIDR。
- 不继承代理环境、不跟随重定向、不自动重试；不允许凭据 URL、自定义请求头或参数覆盖客户端。响应正文最多 2 MiB，拒绝非 identity 内容编码，避免压缩后绕过体积限制。HTTP 超时、状态错误、未完整结束的流不会标通过。
- 准备事务持久化 request/validation/FK/target 后提交，网络 I/O 在事务外；每次发送前重新检查当前权限、JWT 撤销、版本、Key/origin/epoch、端点策略和管理实例租约。5 秒续租任务与本次探测一起取消并等待清理。
- 同键同体运行中返回原 202，完成后返回原结果，不重复联网；另一键不能同时测试同一草稿角色。草稿更改、撤权、凭据撤销或管理代次变化后，结果不能保留 passed 资格。
- 超时/取消记录 unverified；进程丢失后的过期任务在读取时转为 PROBE_RESULT_UNKNOWN，不自动重放未知的网络请求。尚未实施独立后台巡检，未被读取的过期记录可能继续显示 running，不能将其解释为工作进程仍在运行。
- 当前凭据/策略的紧急撤销 HTTP 接口尚未交付；本轮并发撤销测试通过隔离数据库夹具改变状态，验证发送许可守卫。不能把夹具当成已有撤销页面。

## 测试用量

每个出站尝试通过现有 model_trace 总线记录 is_test=true、stage=config_test、实际 profile/credential/adapter/origin 以及关联 validation 的 step_id。无完整 usage 时保留未知值；费用和价格版本为 null/unknown，不套用旧按模型名估算的价格。

普通用量聚合排除配置测试，新增 config_test_usage 独立统计，前端用量页显示测试次数、已知 Token、未知用量次数和未知费用。测试结果同时持久化尝试数/可得使用量；现有 trace 队列仍是可丢弃的观测通道，不作为账单级持久保证。全币种报价/汇率与历史估算迁移仍是后续工作。
