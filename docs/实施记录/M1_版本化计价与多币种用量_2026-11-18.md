# 版本化计价与多币种用量

2026-11-18 实施，承接 M1 的主备模型与同端点重试。用量页按原币种展示费用，区分已计价金额、历史估算、未知费用和实际零费率。按模型展示服务来源，便于辨别同名模型。配置探测单列用量与费用。

通过本地模型配置命令 `register-price` 登记新的价格版本。命令复用已有配置管理员授权、管理租约、幂等键和审计。价格身份使用规范化服务来源与模型标识。每次登记从当前数据库时间生效，金额按指定 Token 单位保存为十进制，原版本保留。价格来源字段填写内部报价版本或供应商费率表引用标识。示例中的变量由操作者填入已确认的值。

```powershell
.venv\Scripts\python.exe -m app.model_config.cli register-price --user-id $adminId --origin $providerOrigin --model $modelId --currency $currency --unit-tokens $billingUnit --input-price $inputPrice --output-price $outputPrice --source $rateReference --request-key $actionId
```

调用追踪的数据库写入端按发送尝试的开始时间和固定配置查找费率。备用模型按实际调用的模型版本匹配。调价期间完成的旧调用仍关联发送尝试开始时生效的价格。已获得价格版本但缺完整用量时，保留价格版本和币种，金额为 `null`。历史估算保留原有费率来源并单列展示。费用汇总保留十进制字符串，旧人民币字段提供已采用价格版本的 CNY 小计。系统保留独立的未知用量、未知价格和未知费用计数。

当前价格表支持单一输入和输出 Token 费率。供应商阶梯价、命中缓存、附加费用及实际账单仍需独立核对。任务级费用上限和精确 Token 预算后续接入。用量汇总使用已有模型追踪数据库通道，异步追踪的可用性和覆盖率影响汇总。代码加载和价格启用走现有本地部署流程。
