# 请求内模型调用、Token 与费用预算

2026-11-18 实施，承接同端点重试、同服务备用模型和版本化计价。启用后，每次进入发布配置中间件的 API 请求获得独立额度，流式响应及继承其上下文的协程共享该额度。预算覆盖经受控适配器发送的聊天与 Embedding 推理。每次重试及备用模型发送单独预留，Embedding 缓存命中及 Ollama 模型摘要校验无需推理额度，配置探测沿用自身限额。

在 `config/agent.yaml` 的 `task_model_budget` 设置单请求限制。仓库默认 `max_calls`、`max_tokens` 为 `null`，`cost_limits` 为空映射。示例为本地联调用的额度。

```yaml
task_model_budget:
  max_calls: 8
  max_tokens: 50000
  cost_limits:
    CNY: "0.50"
    USD: "0.10"
```

配置随本地后端加载，启用任一额度需要先发布模型配置。次数和 Token 上限为正整数，币种额度使用带引号的非负十进制字符串。启用费用限制时，每个可调用模型都需要有适用的价格版本，且币种须包含在 `cost_limits` 中。明确登记为零的本地模型可使用对应币种的零额度。各币种独立计算。

发送前使用该模型声明的上下文窗口、输出限额和请求批量保守预留。聊天按一个上下文窗口及输出上限计，Embedding 按每条输入一个上下文窗口计。费用使用发送尝试开始时匹配的价格版本和十位小数向上取整。在途额度对并行分支可见。完整供应商用量结算后释放多预留的部分，调用次数保留。供应商缺失用量、流中断、取消或状态不明时保留已预留额度。若供应商报告用量超出声明边界，停止后续发送并保留实际用量追踪。

额度用尽、缺少窗口或费率、价格查询失败、币种未配置时，受控适配器在发送前拦截。常规 JSON 业务错误使用 `42903`，聊天 SSE 在流已开始时发出带 `reason` 的 `error` 事件并结束。已在途的分支仍占用自己的额度，拦截的尝试不会写成已发送的用量。

本批实现同进程、单请求模型预算。独立后台任务、跨进程持久任务树、工具执行次数、精确 tokenizer 和供应商实际账单对账继续按原验收矩阵推进。调用前的控制依赖模型声明和供应商遵守协议上限。保守预留会使窗口较大的模型需要较高的入场额度。

## 本地验证

后端 560 项通过，其中预算专项 18 项。专项覆盖并行额度互斥、同端点重试、备用模型、调价、零费率、缺价、币种隔离、用量越界、流式结束和取消。隔离 MySQL 63 项及配置契约 89 项通过。已清理 1,197 个临时测试文件，证据摘要保存在 `.cache/upgrade-m1n/manifest.json`。本批未重启运行中的服务或启用实际额度。
