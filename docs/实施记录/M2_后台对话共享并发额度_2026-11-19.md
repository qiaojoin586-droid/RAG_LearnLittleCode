# M2 后台对话共享并发额度

本批实现 M2-05 的后台对话跨 Worker 并发额度。使用同一数据库的 Worker 共享 8 个执行席位。工作流进入运行状态、已经被领取，且租约和任务期限均有效时占用席位。额度满时新任务继续排队，保留原截止时间和尝试次数。

领取与续租在同一作用域的数据库行锁下串行，两者都在获得行锁后读取数据库时间。取消、完成或租约到期可释放额度。任务由其他 Worker 接管后，旧执行尝试仍受原有租约校验约束。排队任务到达截止时间时可以进入失败终态，即使执行额度已满。

复用已有工作流和配置作用域表，本批无需新增迁移。共享数据库的执行进程需要统一升级才会共同遵守该限额。原有账户级排队限制也继续执行。

后端 639 项、隔离 MySQL 89 项和配置契约 89 项通过。隔离 MySQL 将额度设为 1，两个 Worker 分别通过独立连接同时领取，只产生一次成功领取。另一任务保持排队，直到首个任务取消。后端回归另覆盖租约到期后的接管、旧 Worker 失去权限、任务期限到期后的额度释放。本地业务后端未重启，迁移演练只在隔离数据库执行。
