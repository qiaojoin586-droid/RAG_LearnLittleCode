# 后台对话跨进程取消

2026-11-18 接通 M2-03 的跨进程停止和 M2-04 的数据库状态回读。后台对话的执行模式作为 `workflow_runs.is_detached` 持久化，在交给执行任务前提交。停止接口使用已提交的 MySQL 运行状态，后端本地任务表用于加速同进程中断。

`POST /api/v1/chat/workflows/{workflow_id}/cancel` 核对当前登录身份、账户状态、会话和源消息归属，只对已受理并仍在运行的后台对话提交 `cancelled` 与 `USER_CANCELLED`。条件更新保护并发完成的回复。此时即使接收取消请求的进程没有本地任务，接口也可返回已提交的取消状态。已结束的运行重复取消返回原终态，正在运行的普通短对话返回 HTTP 409 和 `WORKFLOW_NOT_DETACHED`。

执行方在开始前检查运行状态，阻止已经取消的工作进入执行。后台运行期间每秒查询共享数据库，确认取消、租约失效或记录被移除后停止当前任务并释放执行名额。短暂数据库读取失败会重试，取消传播通过数据库状态，二次通知无需送达。模型出站和回复提交仍检查有效租约及终态，取消后无法写入成功结果。已经送到供应商的请求尽力中断，停止接口回执表示本地取消状态已提交。

迁移 `a780cb3ed4f5` 为历史记录补充普通对话默认值，支持重复执行并保护仍在运行的后台记录。隔离测试使用一个进程等待执行，一个独立进程提交取消，验证执行收尾与名额释放。多实例部署、持久任务派发和进程重启后续跑继续由后续阶段实施。

本批验收通过后端全量 598 项、隔离 MySQL 76 项和配置契约 89 项。专项测试覆盖取消先于任务启动、轮询读取失败后重试、普通对话模式限制及晚于完成的取消。清理 789 个测试缓存和临时文件。迁移仅在隔离库执行，本地开发服务未重启。验证报告与文件摘要见仓库的 `.cache/upgrade-m2e/manifest.json`。
