# 后台对话模型预算持久化

这批实现 M2-05 的后台对话跨进程模型预算。任务受理时，在同一个 MySQL 事务中保存原消息、工作流和配置的调用次数、Token 及各币种费用上限。Worker 接管时沿用受理时的预算配置和已占用额度。普通连接内对话沿用请求内预算。

预算选项沿用 `config/agent.yaml` 中的 `task_model_budget`。配置调用数、Token 或任一币种费用上限时启用。默认值未设置额度上限。

每次模型推理出站前，在当前 Worker 租约下锁定共享账本并写入预留。并行模型调用、重试、备用模型和 Embedding 各自占用额度。收到完整用量后按预留时的价格版本结算，重复回执只结算一次。缺少完整用量、请求中断或旧 Worker 已失去租约时保留预留。超出已声明用量上限会记录停止原因。

启用预算的只读后台对话可沿用原有恢复次数和截止时间。重启后的执行尝试继续受原预算控制。迁移前受理的任务保持原重试规则。启用新任务受理前应完成读取同一数据库的后台进程版本更新。

迁移 `f235b08cda49` 新增 `workflow_model_budgets` 和 `workflow_model_reservations`。账本只保存限额、计数、价格版本及预留状态。删除源消息后按工作流级联清理，回退迁移时需先归档保留中的预算回执。工具次数与跨任务并发额度仍按 M2-05 推进。
