# M2 工具调用次数预算

本批接入 M2-05 的任务级工具调用次数限制。后端加载 `config/agent.yaml` 时，`task_model_budget.max_tool_calls` 的正整数值作为调用上限，默认值 `null` 表示不限次数。ReAct、Plan-Execute 及其修复轮共享同一个额度。

工具执行器在调用已注册工具前占用一次额度。执行失败或中断的调用保留已占额度。模型请求不存在的工具时，仍走原有错误处理。尝试超额时停止本轮执行，实时流和后台重连均显示 `TOOL_CALL_LIMIT_EXCEEDED`。超额事件不会触发自动修复重跑。

后台对话在受理时固定工具上限，按工作流租约持久化已占次数。Worker 接管时沿用原额度和计数，旧租约无法继续占用。迁移 `d76487ba19e3` 为现有预算账本增加 `tool_calls`，已有任务沿用受理时的配置。共享数据库的进程应完成更新后再启用额度。

后端 644 项、隔离 MySQL 91 项和配置契约 89 项通过。隔离 MySQL 验证了进程强制退出后沿用计数、两个独立连接争抢最后一次额度、最后一次租约释放后保留原超额原因。迁移只在隔离数据库执行，本地后端未重启。
