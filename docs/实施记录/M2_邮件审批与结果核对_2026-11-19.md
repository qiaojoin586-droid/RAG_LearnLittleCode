# AI 助手邮件审批与结果核对

这批覆盖 M2-02 和 M2-05 的助手邮件。`send_email` 登记待确认申请，绑定收件人、主题、完整正文和格式。用户通过助手的「待确认操作」核对后确认发送或拒绝。有效期沿用 10 分钟。PDF 准备失败时结束本次发送，用户可根据需要重新选择格式。

确认事务验证所有权和预览摘要，持久化单次发送记录与稳定的 Message-ID，并清除申请正文。只有完成该事务的请求可向 SMTP 提交一次邮件。并发确认或重试只读取同一发送记录。发送次数按同一账户过去一小时的 MySQL 记录计数，清理会话不会即时释放额度。

收到 SMTP 成功响应时记录 `accepted`。SMTP 明确拒绝或准备阶段失败时记录 `failed`。提交后的超时、连接中断或持有发送记录的进程退出可以进入 `unknown`。发送期限到期后，其他进程可读取待核对状态。未知状态由人工核对，系统保留同一 Message-ID，供收件方或邮件日志定位。

用户可通过「邮件发送记录」查看结果，核实确实收到后选择「我已核实收件」。该决定只记录人工核对状态 `received`。审批正文在决定后清理，发送记录在会话存在期间保留收件人、主题、格式和 Message-ID。验证码邮件沿用独立入口及现有重试策略。

迁移 `e124af7bc938` 增加 `email_dispatches`。邮件审批仍使用 `operation_approvals` 和 `tool_operations`。新表中的发送记录用于结果核对及限流，存在记录时回退需先归档。其他有副作用的工具将按各自的上游能力接入结果核对。
