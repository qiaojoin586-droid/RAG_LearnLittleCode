## 题集和运行条件

题集共 108 题，精确型号、中文短词、同义表达、多角度、无答案和访问受限各 18 题。72 个合成片段包含 36 个知识库文档和 36 篇笔记。18 篇受限笔记覆盖软删除、撤销索引资格及其他账号所有三种情况。受限记录仍有向量，可以检查 SQL 权限复核能否拦住残留命中。正例逐题冻结目标切片及其应支持的事实。该题集衡量这批合成中文资料上的效果。[语料、题目与标注](../../tests/fixtures/rag_m3_14_ablation.json)

| 组合 | 执行的检索路径 |
| --- | --- |
| A | 原问题向量检索 |
| B | A 加 MySQL 字面及 ngram 全文检索，使用 RRF 融合 |
| C | B 加本地 BGE CrossEncoder INT8，最多重排 30 个候选 |
| D | C 加本地 Qwen 生成有限改写，通过服务端校验后再检索 |

四组共用真实 Chroma、临时 MySQL 8、同一组 Ollama 模型和同一份索引。实验将各组每个来源的候选深度对齐为 20，最终最多返回 5 个证据块。在每组预热后按冻结种子打乱问题，每批 4 题并发，轮换四组的执行顺序，组间等待仍在执行的重排计算结束。每个请求仍执行服务端 5 秒总预算和各阶段超时。晚到、被拒绝或未触发的增强均计入对应组合的实际成绩。

## 指标口径

- **召回和排序**。在 72 道有答案的题上计算宏平均。Recall@20 使用融合后、重排前的前 20 个候选，nDCG@5 和 MRR@5 使用实际返回的证据。空金标准单独衡量拒答。报告保留每题的排名、各来源对前 20 条相关切片的独有贡献及相邻组合的指标差值。
- **证据和引用**。对编号、片段正文哈希与 SQL 当前授权版本逐条核对。另用同一个本机回答模型做摘录式问答，要求为每条答复选择原文短句和证据编号。只有短句确实来自所引片段且包含题目标注事实才计为引用支持。相同问题与完全相同的编号证据复用同一份回答。另记负例拒答率、事实覆盖率和格式错误。开放式回答需要另外评估。
- **查询漂移**。统计生成器已返回的结构化改写中，因实体、限制条件或表达偏移被原有校验拒绝的比例。没有可计的模型输出时该指标为空。另记改写尝试、实际扩展检索和回退原因。
- **时延和费用**。延迟覆盖从检索入口到证据组装返回的全过程，按最近秩取 P50/P95。逐条引用复核及回答探针单独执行。所有推理均在本机完成，费用指标仅统计外部 API 调用，不含硬件和电费。

## 本机实测与采用决定

使用 MySQL 8.0.42（ngram 长度 2）、真实 Chroma、Ollama 的 Qwen3 0.6B 嵌入与回答模型，以及 CPU 上的 BGE INT8 重排。四组共 432 次计分检索。每组 108 次均返回结果。逐题排名、引用对应关系、模型摘要、分组统计以及各门槛的通过状态保存在[本次验收证据](../../.cache/upgrade-m3-ablation/retrieval/M3-14.json)。

| 组合 | Recall@20 | nDCG@5 | MRR@5 | 检索 P50 | 检索 P95 | 采用判定 |
| --- | ---: | ---: | ---: | ---: | ---: | --- |
| A 向量 | 1.0000 | 0.9278 | 0.9125 | 210 ms | 389 ms | 本机基线达标 |
| B 混合 | 1.0000 | 0.9112 | 0.8905 | 206 ms | 343 ms | 排序相对 A 下降 0.0167 |
| C 混合加重排 | 1.0000 | 0.9041 | 0.8863 | 1703 ms | 1772 ms | 排序与延迟均未达标 |
| D 再加查询扩展 | 1.0000 | 0.9075 | 0.8905 | 1834 ms | 2407 ms | 相对 C 的提升 0.0034，低于 0.01，延迟超限 |

B 在中文短词上的 nDCG@5 从 0.9104 升至 0.9590，在同义表达上从 0.8009 降至 0.6856。B 前 20 名候选中有 44.68% 被多个检索分支同时找到，最终证据无重复。C 和 D 各有 90 次重排超时，均按既有策略退回融合结果。D 尝试改写 23 次，12 次发起扩展检索，另外 11 次因改写偏离约束被拒绝。

共核验 2160 个证据位置，四组定位正确率均为 100%，受限正文外发及引用均为 0，每个成功问题的外部 API 费用均为 0 元。正例须覆盖应答事实且每条摘录均有正确引用，负例须按约定返回空答案。432 份组别输入对应 231 份不同的摘录式问答输入。各组引用支持率为 29.2% 至 31.4%。每组 36 道负例均未得到约定的空答案。有些回答引用了可访问但与问题无关的段落。该结果限定于本轮回答模型和提示词。

本轮完成对照评测，M3-14 验收矩阵中的 `approved_quality_and_cost_gates_passed` 为 `false`。2026-11-24 用户选择保留现有 SQL 兜底，记录 B 未达标，本地关闭 C、D。项目配置中的 `reranker.enabled` 已设为 `false`，下次启动后跳过重排模型加载。查询扩展仍需独立角色及采用依据。[本地重排配置](../../config/chroma.yaml)
