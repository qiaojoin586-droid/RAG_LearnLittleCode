# M3-07 回答引用证据链

用户可以在助手回答下方的「引用原文」中展开与正文相同的编号，例如 `[E1]`。面板显示文档名或笔记标题、原文片段及字符区间，PDF 另显示物理页码，有章节的文档显示章节标题。收起后再次展开会重新读取。离开会话再回来，仍能从原回答打开引用。

## 从召回到原文

1. 检索服务按本轮排序给通过归属、版本和切片校验的来源分配编号。原文截取或逐项摘要与各自的编号一起进入低信任检索资料。摘要调用期间若原文失效，后续复核会移除对应结果。
2. 回答模型收到服务端引用格式规则。已发布模型使用实际出站的上下文判断资料是否保留。服务端在完整回答中匹配本轮提供的编号，再核对资源是否仍已发布。检索结果缺少原文清单、模型自行写出的未知编号或已撤销的来源均不生成原文入口。
3. 助手消息和已确认编号在同一事务提交。每个编号保存资源类型、资源 ID、版本、切片序号、定位信息摘要、最终排名和重排分数。实时完成事件与断线重放通过 `reply_message_id` 和 `citation_ids` 指向已提交的回答。原先完成事件中的来源预览改为按需读取。历史消息返回编号，旧回答的编号列表为空。
4. 前端使用登录凭据请求 `GET /api/v1/chat/{session_id}/messages/{message_id}/citations/{citation_id}`。服务端按会话所有者与助手消息查找编号，复核资源归属、检索资格、版本和位置。文档还会核对原文件及切片内容的哈希。改版、移除、撤销检索资格或相同原文件重新切片后位置变化，旧引用均返回 404。字符位置按 Unicode 字符计算，界面展示从 1 开始的闭区间。

## 本地验收

回归覆盖真实两页 PDF、笔记原文、逐条摘要、分段 SSE、持久消息和断线重放。还覆盖未知编号、跨用户和跨消息访问、改版、删除、撤销检索资格、相同文件的切片变更，以及 OpenAI 兼容和 Ollama 原生请求的上下文裁剪。模型响应来自隔离测试，回答对证据的语义支持度留待 M3-14 冻结题集评测。[本轮验收证据](../../.cache/upgrade-m3-citations/faults/M3-07.json)
