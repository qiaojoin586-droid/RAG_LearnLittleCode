# M3-10 有限查询扩展

原问题同时检索知识库和笔记的向量与关键词。遇到比较、同义术语或多个明确方面的问题，服务可以并行请求一次改写。通过校验的改写只查向量。精确型号或单一术语直接使用原问题。重排和摘要始终使用用户原问题。

## 改写边界

策略版本为 `adaptive-lexical-v1`。独立生成器的输入只有原问题和 384 个输出 Token 的预算。含引用笔记标记、结构化指令或超过 512 个字符的输入会跳过扩展。个人记忆、权限条件、会话历史及候选正文均不传给生成器。每轮最多生成一次，生成时间最多 1 秒，同时服从召回和父请求的截止时间。

回复须为仅含 `queries` 的 JSON 对象，数组最多两项，每项最长 512 字符。服务去掉空项、原问题和重复项。任一改写不符合约束，整组回退。首版校验只接受已登记的近义表达，以及受限的同一主题双方面表达。例如“冷却泵的安装步骤和维护方法有哪些？”可以拆成安装与维护两次检索。引号内字面内容、型号大小写、否定位置、日期、比较符和单位均参与核对。规则未能识别的自由改写会回退，这部分覆盖率留给 M3-14 测量。

每个请求共用四个检索并发位置，知识库和笔记在相同语义空间复用同一句查询的嵌入。各路结果先在数据库核验所有者、可检索状态及正文版本，再参与融合、重排和证据组装。同一切片保留命中它的改写序号，多个改写在外层融合中合计获得一份排名。

## 默认行为与故障

当前发布清单仍使用 v2。聊天和独立检索入口默认关闭扩展。本轮通过服务端注入固定生成器进行隔离验收。生产适配器、OpenAI 兼容与 Ollama 的独立角色发布属于 M3-15，实际启用还需通过 M3-14 质量与成本验收。独立检索接口显式启用 HyDE 时，仍然保留原问题向量检索；同一请求只执行一种扩展策略。

独立检索响应的 `query_expansion` 给出策略版本、状态、已发起检索的改写数和回退原因。超时、格式错误、约束变化、空结果或生成器异常均保留已完成的原问题检索。单个来源出错沿用 `failed_sources` 标识，全部来源不可用沿用现有错误处理。诊断只使用固定原因码。

生成器到期后会收到取消信号，原问题可立即返回。连接清理期间，生成任务仍由有并发上限的任务管理器持有，迟到的结果会被丢弃。

49 个专项用例通过，包含 16 个冻结约束样例。目标证据在最终结果中排第 1，越权或失效正文进入重排的次数为 0。回归同时复测了默认关闭扩展的固定负载，4 并发、100 次请求、0 错误，P95 为 26.795 毫秒。该延迟对应本地固定向量。[本轮验收证据](../../.cache/upgrade-m3-expansion/retrieval/M3-10.json)
