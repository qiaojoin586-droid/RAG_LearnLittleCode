# M3 索引对账和孤儿修复

M3-01 在本地嵌入式 Chroma 部署下支持全量对账。工具扫描 YAML 配置的旧集合和可解析的索引版本，别名共用同一物理集合时只扫描一次。MySQL 提供来源所有权、删除状态、任务状态和期望切片数。工具校验集合 ID、有效切片数、笔记正文与索引版本，以及新入库文档的源摘要。

## 本地命令

在项目根目录执行。后端和对账命令共用工作区的独占锁，维护窗口内由一个进程访问嵌入式 Chroma。

```powershell
.\.venv\Scripts\python.exe -m app.rag.reconcile_cli
.\.venv\Scripts\python.exe -m app.rag.reconcile_cli --owner <用户UUID>
.\.venv\Scripts\python.exe -m app.rag.reconcile_cli --owner <用户UUID> --apply
.\.venv\Scripts\python.exe -m app.rag.note_index_admin rebuild <用户UUID> <笔记UUID>
```

默认命令从 SQLite 目录快照读取元数据，报告包含计数、少量来源 ID 和任务汇总。集合身份冲突、目录读失败或无法解析的版本会出现在报告中，命令退出码为 `2`。`--apply` 会重新扫描，再次核对单个用户的来源与向量元数据，最后按精确向量 ID 清理来源不存在或已进入回收站的向量。`counts` 是清理前的计数，`purged_vectors` 是本次确认删除的数量。可以再次运行默认命令查看清理结果。

归属不一致、版本过旧、文档缺片和重复切片保留为报告项。针对缺失或失效的笔记索引，可用 `rebuild` 创建新版本的任务，Worker 会读取当前正文并使用当前绑定重建。失败任务沿用 `failed` 和 `retry` 命令。索引切换的增量追平和文档缺片重建属于后续验收。

## 本地验收

只读盘点得到 163 个有效知识库切片、15 个有效笔记向量、3 个笔记孤儿向量和 2 篇缺索引笔记。业务目录仅执行盘点。孤儿清理、重复执行、归属隔离、集合替换保护与修复前复查在隔离 Chroma 验证。
